Open your Mac like it unfolds.

Lid Blur is a tiny menu bar app that melts your MacBook screen into a soft blur as the lid closes, then eases it back into focus from the hinge up as you open it.

Download for macOS Install guide

Latest release · Free and open source · macOS 13 Ventura or later · Apple silicon and Intel

Follows the hinge, smoothly

Inspired by the gentle open animation of foldable phones, built to stay out of your way.

Tied to the lid angle

On MacBooks with a hinge sensor, the blur tracks the angle of the lid through an easing spring, so slow and quick opens both glide into focus.

Clears from the bottom up

The Unfold style sharpens the picture from the hinge upwards, and the darkness lifts before the blur resolves. Prefer an even fade? Switch to Uniform.

Works on every MacBook

No sensor? Lid Blur falls back to lid and wake events and plays the unfold each time the screen comes back. Click-through, built-in display only.

Install

Pick whichever way you like. Every option installs the same app, starts it, and turns on Launch at Login.

  1. Download LidBlur.dmg from the latest release.

  2. Open the DMG and drag Lid Blur onto the Applications folder.

  3. Open Lid Blur from Applications. The first time, macOS will block it because the app isn't notarized; see Opening it the first time below.

  4. Look for the laptop icon in the menu bar. That's it.

  1. Add the tap and install the cask:

    $ brew tap thomasmelak/lid-blur https://github.com/thomasmelak/lid-blur
$ brew install --cask lid-blur

  2. Homebrew clears the quarantine flag and opens the app for you, so there's no security prompt.

  3. To update later:

    $ brew upgrade --cask --greedy lid-blur

  1. Paste this into Terminal:

    $ curl -fsSL https://raw.githubusercontent.com/thomasmelak/lid-blur/main/install.sh | bash

  2. The script downloads the latest release into /Applications, clears the quarantine flag and starts the app. If no release exists yet it builds from source, which needs the Xcode Command Line Tools (xcode-select --install).

  1. Make sure the Xcode Command Line Tools are installed (xcode-select --install).

  2. Clone, build and install:

    $ git clone https://github.com/thomasmelak/lid-blur.git
$ cd lid-blur
$ make install

Opening it the first time

Lid Blur is signed but not notarized by Apple, so the first launch of a downloaded copy shows a "cannot be opened" or "Apple could not verify" message. Either:

Open System Settings › Privacy & Security, scroll down to the message about Lid Blur and click Open Anyway, or remove the quarantine flag in Terminal:

$ xattr -dr com.apple.quarantine "/Applications/Lid Blur.app"

Homebrew and the one-line installer do this for you.

Using it

Everything lives in the menu bar icon.

OptionWhat it does
EnabledTurns the effect on or off
Preview AnimationPlays the blur so you can try settings without moving the lid
StyleUnfold clears from the bottom up, Uniform fades evenly
IntensitySubtle, Normal or Strong
Fully sharp from …Slider for the lid angle at which the screen becomes fully sharp, 30° to 130° (sensor Macs only)
Use Current Lid AngleSets that angle to wherever your lid is right now
Launch at LoginStarts Lid Blur when you log in (on by default)

Uninstall

Any of these removes the app, its login item and its settings.

From the menu bar

Click the laptop icon and choose Uninstall Lid Blur…

Homebrew

$ brew uninstall --cask --zap lid-blur

Script

$ curl -fsSL https://raw.githubusercontent.com/thomasmelak/lid-blur/main/uninstall.sh | bash

Or run make uninstall in a clone of the repository.

Questions

Which Macs have the lid angle sensor?

The 16-inch MacBook Pro (2019) and most Apple silicon MacBook Air and MacBook Pro models from 2021 onwards. The first line of the menu says whether yours was found. Without it, Lid Blur uses lid open/close and wake events instead.

Does it need any permissions?

No. The hinge angle is read from Apple's built-in HID sensor, which needs no special access, and the overlay is a click-through window on the built-in display only.

The blur looks like a flat fade.

If Reduce transparency is on in System Settings › Accessibility › Display, macOS replaces blurs with a solid tint, so the effect becomes a fade.

Will it slow my Mac down?

The sensor is polled slowly whenever the lid isn't moving, and the overlay is hidden entirely while the screen is sharp.
